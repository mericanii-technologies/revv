# Verified examples

All four generated by Qwen3.8-27B (IQ3_XXS) through revv on an RTX 3060, ~40 tok/s,
and verified by execution — not by eyeballing.

| task | result | verification |
|---|---|---|
| `hexagon.py` — ball bouncing inside a spinning hexagon (pygame) | pass, first attempt | ran 300 frames headless; ball position checked against the hexagon polygon every frame (`hex_frame_150.png` is frame 150) |
| `pelican.svg` — pelican riding a bicycle | pass, first attempt | rendered (`pelican.svg.png`) |
| `lru_cache.py` — thread-safe LRU cache with TTL + its own unittest suite | pass, first attempt | executed: 5/5 tests pass, including the concurrency test |
| `reduce5.cu` — CUDA parallel reduction, 10M floats | pass on attempt 5 | compiled with nvcc and run on the 3060; relative error 6e-13, exit 0 |

The CUDA one is worth reading honestly: attempts 1–4 failed — the model kept
writing the same subtly wrong shared-memory reduction idiom, deterministically,
even across full rewrites. What fixed it was feeding the error output back with
temperature on the retry. That is the point of running locally: retries are free,
and code is verifiable. A control program (thrust) confirmed the GPU itself was
computing correctly throughout.
